# 内容规范

## 站点定位

- 正式站名：Cupppa Lab；中文副名：一盏实验室。不刻意解释多出的 `p`。
- 中文标语：冲泡想法，动手试验，留下记录。
- 英文标语：Brew ideas. Test things. Keep notes.
- 中文介绍：一盏实验室是一个记录技术实践、工具探索和个人思考的小型实验室。
- 英文介绍：A personal lab for technical practice, tools, automation, and ideas.

## 内容维护

- 新文章参考 `article-template.org`，文件名使用 `YYYY-MM-DD-short-name.org`。
- `date` 保留首次发布日期；`updated` 仅在文章实质性更新时调整，不因标点或样式修改刷新。
- `category` 只填一个主分类。当前为 `tech`（技术实践），其他分类有内容后再启用。
- 标签使用小写英文短名，每篇最多 5 个，不重复主分类。目前只记录 `filetags`，不建标签页。
- 新文章同步加入文章索引和对应分类页；暂时手工维护。
- 更新或重新分类不移动已发布文章，保持 URL 稳定。
- `backup/` 是历史快照，不作为当前内容源。
