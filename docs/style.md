# 内容规范

## 文章结构

- 每篇文章使用一个明确的 `#+title:`。
- 文章文件放在 `org/posts/`，文件名使用 `YYYY-MM-DD-short-name.org`。
- 首页只保留站点介绍和文章入口，不复制完整正文。
- 文章内部链接优先使用 Org 的 `file:` 链接或完整 HTTPS URL。

## 写作要求

- 标题应准确描述文章主题，不使用夸张或无法验证的结论。
- 技术内容说明适用环境、版本或前提条件。
- 外部资料使用链接引用；转载、推断和个人判断要明确区分。
- 命令、文件名、配置项和代码使用 Org 的代码标记或代码块。
- 不为了排版直接编辑生成的 HTML。

## 发布前检查

1. 确认标题、链接和代码块完整。
2. 确认文章没有依赖本地私有路径或未提交附件。
3. 执行 `./build.sh`。
4. 执行 `./scripts/check-site.sh`。
5. 检查生成后的页面标题和新增链接。
